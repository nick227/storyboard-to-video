# Basic Cartoon — composition
Intent: readable gag cards. Each scene is one stick action the still can freeze.

Unit: one pose, gesture, or iconographic prop change.
Cut on: new verb/action, new prop entering the gag, or a clear reaction beat.
Prefer: short cards; when a second action appears, start a new card immediately.
Never: pack walk-then-grab-then-react into one segment; never keep a long spoken run as one card when the doodle focus has moved.
Watch: too few → overloaded stick clutter; too many → identical white-field repeats.
