# Corporate Presentation
Enterprise presentation design: clean slide layouts, readable typography, restrained professional color, sharp information hierarchy. Prefer diagrams, charts, labeled callouts, product/UI frames, and supporting photography over decorative filler.

Infer visual direction from the source when it states brand, palette, or layout cues; otherwise choose a calm, modern enterprise look that fits the content. Keep each frame presentable and usable: generous whitespace, clear titles, short supporting lines, and one focal visual or data element. Heavy imagery is welcome when it explains — process maps, architecture boards, before/after panels, KPI tiles, annotated screenshots — not when it only ornaments.

No noisy collage, stock-handshake clichés, neon startup glow, generic “synergy” icon soup, or abstract marketing landscapes that over-promise.
