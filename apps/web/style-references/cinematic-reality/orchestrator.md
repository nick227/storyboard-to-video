# Cinematic Reality — composition
Intent: coverage like a director’s reel. Each scene is one motivated frame change.

Unit: one cinematic coverage beat (establish, act, or react — not all three).
Cut on: new framing intent, light shift, physical action, or reaction that would get its own setup.
Prefer: establish → act → react across cards; give important moves their own still.
Never: merge several distinct visual moments into one long card; never cut mid-thought without a new image to land on.
Watch: too few → muddy coverage; too many → micro-cuts that feel like slideshow spam.
