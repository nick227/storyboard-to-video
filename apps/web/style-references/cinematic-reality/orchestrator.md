# Cinematic Reality — composition
Intent: coverage like a director’s reel. Each scene is one motivated frame change.

Unit: one cinematic coverage beat (establish, act, react, bridge, or hold — not several at once).
Cut on: new framing intent, light shift, physical action, reaction, or pause that would get its own setup.
Prefer: establish → act → react across cards; use brief bridge/hold cards between dialogue when narration supports breath.
Never: merge several distinct visual moments into one long card; never invent a silent card with no narration text.
Watch: too few → muddy coverage; too many → micro-cuts that feel like slideshow spam.
